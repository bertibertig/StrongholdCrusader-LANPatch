**SC LAN Patch 1.1.0** bringt eine **größere Bedienoberfläche für hohe
Auflösungen**. Mit `UIScale=1.5` (oder `2` …) in `sclanpatch.ini` werden
Leiste, Menüs und Dialoge vergrößert. Die Karte bleibt in voller Auflösung.
Der LAN-Teil ist unverändert.

> Die Spieldateien sind **nicht** enthalten. Ihr braucht eine eigene Kopie des
> Spiels. Die Spiel-EXE wird nicht verändert. Für das LAN-Spiel muss der Patch
> auf **allen** Mitspieler-PCs installiert sein. Die UI-Skalierung kann jeder
> für sich ein- oder ausschalten.

## Installation

| System | Download | Anleitung |
|---|---|---|
| Windows 10 / 11 | `SC-LANPatch-1.1.0-Windows.zip` | ZIP entpacken → `install.bat` per Rechtsklick „Als Administrator ausführen“ ([Anleitung](https://github.com/bertibertig/StrongholdCrusader-LANPatch/blob/v1.1.0/docs/ANLEITUNG-Windows.md)) |
| Linux (Proton / Wine / Steam) | `SC-LANPatch-1.1.0-Linux.tar.gz` | `./sclan-linux.sh install` → `./sclan-linux.sh start` ([Anleitung](https://github.com/bertibertig/StrongholdCrusader-LANPatch/blob/v1.1.0/docs/ANLEITUNG-Linux.md)) |

Im Spiel: **Mehrspieler → „Internet TCP/IP Connection For DirectPlay“**. Host
klickt **Host**, Mitspieler lassen das **IP-Feld leer** und klicken **Beitreten**.

**Update von 1.0.0:** `dplayx.dll` im Spielordner ersetzen. In eure vorhandene
`sclanpatch.ini` die Zeile `UIScale=1.5` eintragen (ohne die Zeile bleibt die
Skalierung aus).

## Neu

- **UI-Skalierung (`UIScale=`).** Das Spiel kann 1920×1080, 2560×1440 usw.,
  zeichnet die Bedienoberfläche dort aber in Originalgröße, also winzig. Jetzt
  werden vergrößert:
  - die **Menüs** (ganze Menüseite mit Steinrahmen, oder der Menükern, wenn die
    Seite mit dem gewünschten Faktor nicht passt),
  - im Spiel die **untere Leiste** samt Schreiber und Minimap,
  - **Dialoge im Spiel** (Esc-Menü, Optionen, Speichern/Laden, Rückfragen …).

  Mausklicks in den vergrößerten Bereichen treffen die Buttons. Der Faktor wird
  pro Bereich automatisch so weit begrenzt, dass alles auf den Bildschirm
  passt. Ganzzahlige Faktoren (2, 3) sind pixelgenau scharf, krumme (1.5) weich
  interpoliert. Funktioniert mit `Stronghold Crusader.exe` und
  `Stronghold_Crusader_Extreme.exe`.
- Empfehlung: im Spiel die native Auflösung wählen, dann 1920×1080 → `1.5`,
  1920×1200 / 2560×1440 → `2`.

## Bekannte Einschränkungen

- **UI-Skalierung:** Kleine Einblendungen direkt über der Karte werden nicht
  vergrößert (Rohstoffliste oben links, Taktik-Leiste rechts in Extreme,
  Tooltips).
- **UI-Skalierung:** Auf echtem Windows noch nicht getestet, ebenso
  Fenstermodus, Videos und Karteneditor. Rückmeldungen mit `sclanpatch.log`
  sind willkommen.
- Auf Windows 10/11 ist auch der LAN-Teil noch nicht auf echter Hardware
  getestet.
- Unter Linux ist Microsofts DirectPlay im Prefix Pflicht. Wines eigenes kann
  keine Spiele hosten. `sclan-linux.sh install` erledigt das.
- Spieler **ohne** Patch können einem gepatchten Host beitreten. Sie finden
  andere aber nur auf dem alten Weg.
- Der erste Suchlauf kann bis zu ~5 Sekunden dauern (DirectPlay wiederholt die
  Suche in diesem Takt).
- `DiscoveryPort` muss auf allen PCs gleich sein (Standard 47630).

## Für Entwickler

- `src/uiscale.c`: DirectDraw-Hooks (Import `DirectDrawCreate` + COM-Vtables),
  Schattenkopie des Bildschirms, Skalierung vor `Flip`. Spielzustand
  (Szene, offener Dialog) kommt aus Globals der EXE, die per Code-Signatur
  gefunden werden – keine festen Adressen.
- `test/uilab.sh`: Spiel einzeln und unsichtbar starten (Xvfb, Ton auf
  Null-Sink), klicken, Screenshots.
- `UIDebug=1` in der ini: zusätzliches Logging und Speicherabbilder auf Anfrage.
