Erste Version des **SC LAN Patch**: Stronghold Crusader HD / Extreme HD findet
Mitspieler im LAN jetzt auch dann, wenn ihr euch bisher „nicht gesehen“ habt,
etwa wegen VPN-, VirtualBox- oder Hyper-V-Adaptern oder über Tailscale.

> Die Spieldateien sind **nicht** enthalten. Ihr braucht eine eigene Kopie des
> Spiels. Die Spiel-EXE wird nicht verändert. Der Patch muss auf **allen**
> Mitspieler-PCs installiert sein.

## Installation

| System | Download | Anleitung |
|---|---|---|
| Windows 10 / 11 | `SC-LANPatch-1.0.0-Windows.zip` | ZIP entpacken → `install.bat` per Rechtsklick „Als Administrator ausführen“ ([Anleitung](https://github.com/bertibertig/StrongholdCrusader-LANPatch/blob/v1.0.0/docs/ANLEITUNG-Windows.md)) |
| Linux (Proton / Wine / Steam) | `SC-LANPatch-1.0.0-Linux.tar.gz` | `./sclan-linux.sh install` → `./sclan-linux.sh start` ([Anleitung](https://github.com/bertibertig/StrongholdCrusader-LANPatch/blob/v1.0.0/docs/ANLEITUNG-Linux.md)) |

Im Spiel: **Mehrspieler → „Internet TCP/IP Connection For DirectPlay“**. Host
klickt **Host**, Mitspieler lassen das **IP-Feld leer** und klicken **Beitreten**.

## Neu

- **Spielsuche über alle Netzwerkadapter.** DirectPlays Broadcast geht nicht
  mehr nur über einen (oft falschen) Adapter hinaus, sondern über jeden aktiven.
- **TCP-Nachbarsuche (Port 47630).** Gepatchte Spiele finden sich gegenseitig
  per TCP im eigenen Subnetz und tauschen Peer-Listen aus. Die Spielsuche geht
  dann direkt an jeden gefundenen PC.
- **Spielen über VPN / Internet.** Mit `Peers=` in `sclanpatch.ini`
  (Tailscale, ZeroTier, Hamachi, Radmin …). Es reicht, wenn eine Seite die
  andere kennt.
- **Richtige eigene IP.** Die echte LAN-Karte wird vor virtuellen Adaptern
  gemeldet. Das gilt auch für die Anzeige „Eure IP“ im Spiel.
- **Stabilere Spielverbindung.** `TCP_NODELAY` und Keepalive auf den
  DirectPlay-Verbindungen.
- **Windows-Installer.** Er aktiviert DirectPlay, legt Firewall-Regeln an und
  warnt bei Netzwerkprofil „Öffentlich“. Ein Deinstaller ist dabei.
- **Linux-Skript `sclan-linux.sh`.** `install` richtet ein Proton-/Wine-/Steam-Prefix
  ein und installiert darin Microsofts DirectPlay (aus dem offiziellen
  DirectX-Redistributable, mit Prüfsumme). Dazu kommen `start`, `status`,
  `uninstall` und `start --headless` (unsichtbar, Ton auf Null-Sink).
- Konfiguration über `sclanpatch.ini`, Protokoll in `sclanpatch.log`.

## Bekannte Einschränkungen

- Auf Windows 10/11 noch nicht auf echter Hardware getestet. Rückmeldungen
  mit `sclanpatch.log` sind willkommen.
- Unter Linux ist Microsofts DirectPlay im Prefix Pflicht. Wines eigenes kann
  keine Spiele hosten. `sclan-linux.sh install` erledigt das.
- Spieler **ohne** Patch können einem gepatchten Host beitreten. Sie finden
  andere aber nur auf dem alten Weg.
- Der erste Suchlauf kann bis zu ~5 Sekunden dauern (DirectPlay wiederholt die
  Suche in diesem Takt).
- `DiscoveryPort` muss auf allen PCs gleich sein (Standard 47630).

## Für Entwickler

- Build: `make` / `make dist` (MinGW-w64 i686). Unter Windows: MSYS2 MINGW32
  und `make CROSS=`.
- `test/netlab.sh`: virtuelles LAN aus Network-Namespaces mit zwei
  Proton-Instanzen, ohne root.
- `tools/dptest.c`: DirectPlay-Testprogramm, das sich wie das Spiel verhält.
